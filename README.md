# Study Progress & Skill Tracker
A complete EdTech web application for tracking learning plans, study tasks, quizzes, and skills.

## Dependencies
- Node.js (v16+)
- React 18
- Vite
- TailwindCSS
- Recharts

## Installation
```bash
npm install
```

## Build
```bash
npm run build
```

## Run
```bash
npm run dev
```

## Test
```bash
npm run test
```

## Usage
Open the application at the local host and construct learning plans, log tasks, play custom quizzes, and view visual skill charts.
